# PRODUCT

Nibblio — instant browser multiplayer worm arena (docs/MASTER_SPEC.md §1).
Candy-space art direction (ART_STYLE.md), guest-first frictionless entry
(nickname → PLAY), 40-player arenas, six skins, powerups, leaderboard.

Session loop: join in <5 s → eat/grow → risk boost duels → die → loot rush →
PLAY AGAIN. Progression hooks (persisted): personal bests, total stats,
future coins/unlock economy (schema shipped, spec §81 — no pay-to-win).

Surfaces: game (/), how-to-play + legal (/legal/*), PWA install (manifest +
offline shell for statics), social preview card. Reach: desktop
Chrome/Edge/Firefox/Safari + Android Chrome + iOS Safari (MOBILE.md).
